## 6. Navigation loading hardened

`src/hooks/use-navigation-loading.ts` (used by `progress-loader.tsx`; user-facing behavior for normal internal navigation preserved):

- Only triggers for genuine same-tab internal navigation:
  - ignores `event.defaultPrevented`, non-left clicks (`event.button !== 0`), and `metaKey`/`ctrlKey`/`shiftKey`/`altKey` modified clicks;
  - ignores `target` other than `_self`, `download` links, hash-only links, cross-origin URLs, and malformed URLs;
  - same-page check is now query-aware (`pathname + search`) instead of raw href vs pathname.
- Stuck-state safety: an **8 s safety timeout** resets the indicator if navigation never completes; timers are cleared on pathname change and unmount.
- Removed the pointless `beforeunload → setIsLoading(true)` handler (could only set state that no longer has a chance to reset if a reader cancels unload; the page unloads anyway).
- No dependency added; no architecture change.
